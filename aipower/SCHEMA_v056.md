# Cross-Cutting Views and Reviewed Research: v0.56

The shared `crosscuttingViews` contract from `SCHEMA_v055.md` now includes
`sovereignty` and `delegation`, alongside `knowledge` and `economy`.
The cyber view retains its existing URL and specialized controls.

Sovereignty separates jurisdiction/access, cloud switching costs, open weights,
national capacity and energy infrastructure. No country receives a synthetic
sovereignty score. Local hosting, ownership, model licensing and the ability to
replace suppliers remain different properties.

Delegation separates institutional workflows, command, financial authority,
human verification and agent oversight. Membership is not a claim that AI has
legal authority or operates autonomously. The event's evidence context,
delegated authority, implementation stage and caveats retain their meaning.
An optional track `outcome_stages` list intersects arc membership with
`research_outcome_stage`. It keeps general employment/exposure statistics and
laboratory synthesis out of the human-verification track. Matching is based
on metadata, not title keywords. Unknown outcomes are excluded by this gate.
The shared artifact vocabulary adds `judgment` for court decisions, without
classifying them as legislation, incidents or commercial policies.

`review/crosscutting-expansion-2026-11-10/accepted.json` contains the editorial
decisions and bilingual accepted records. Original agent packets are retained,
including rejected/deferred candidates. No claim status is upgraded merely
because a new event belongs to an arc.

`scripts/migrate_crosscutting_expansion.py` verifies an immutable compressed
v0.55 baseline and stages both languages. A repeated application must match the
same result; unexpected concurrent changes fail closed. A subsequent
view-definition-only rebuild is permitted when all evidence matches the same
reviewed package under the previously embedded definitions. This does not
accept unrelated concurrent evidence edits. The migration journal
records field changes, new IDs, sources and links. Old IDs, dates and semantic
edges are retained unless a reviewed update explicitly identifies a field.

New arc links use `part_of_arc`. Event-to-event links require an explicit
editorial rationale; proximity in time is not a causal relation. Source
registry IDs are retained, URLs deduplicated and backwards links rebuilt.

Each accepted record distinguishes the date of the event, publication or
observation. Benchmarks, preclinical results, field experiments, commercial
claims and rules are not interchangeable evidence of real-world outcomes.
