## Воспроизведение

`scripts/migrate_stack_refresh.py` принимает только SHA-256-закреплённую пару v0.50 и пишет обе версии после успешной проверки. `tests/stack_refresh_test.py` восстанавливает базу цепочкой предыдущих миграций, сравнивает результат и проверяет сохранность. Контракты арок не расширены: принадлежность `part_of_arc` тематическая, отдельные доказательные связи ограничены указанным механизмом.

```sh
python3 scripts/migrate_stack_refresh.py --input /path/to/v050 --output /tmp/v051
python3 scripts/build.py
python3 scripts/validate.py
python3 tests/stack_refresh_test.py
python3 tests/stack_refresh_browser_test.py --chromium /path/to/chrome
```

Результаты: `migration-audit.json`, `tests-results.json`, `browser-tests.json`, `full-browser-tests.json`. Проверка структуры и навигации не является проверкой причинности или всех опубликованных источников.

Пройдено 992 общих проверки данных и 1014 проверок миграции. Браузер: 176 регрессионных и 826 целевых проверок RU/EN, включая все 41 новые карточки, переходы по аркам, постоянные ссылки через HTTP и экраны 1440/390 px. Ошибок JavaScript и горизонтального переполнения страницы не обнаружено; временный сервер остановлен.
